让已有设计，成为下一次创作的起点 LOCAL MODEL SEARCH

在你的电脑上建立 3D 模型「形状检索库」：拖入一个模型，即可按几何形状找到相似的已有设计。 深度 Shape 特征 + 余弦相似度检索，Windows x64 / M 系列 Mac 免 Python 安装。

⬇ 下载平台安装包 查看源码

它能做什么

面向本地设计资产的形状检索引擎，为「复用已有设计」而生。

🗂

建立本地检索库

选择一个放有 3D 模型的文件夹，自动建立形状索引；支持多个库并存。

🔍

按形状检索

拖入 STEP / STL / OBJ / 3MF / PLY / GLB 等模型，按形状相似度返回 Top-K 结果。

🧭

3D 预览

查询与结果均可本地交互预览（three.js 渲染），支持「以此模型继续检索」二跳搜索。

✏️

在 CAD 中打开编辑

检索结果可直接交给本机已安装的 CAD 程序修改：创建副本编辑或直接编辑原文件；多个程序可选。

🔒

全程离线

服务仅监听 127.0.0.1（带随机会话令牌）；完整安装包下载后无需联网，模型与特征不出本机。

快速开始（只需两步）

安装包内置 Python、CPU 推理依赖和权重；首次启动不安装 pip 依赖。请以 Release 实际附件为准，Source code ZIP 不是安装包。

🪟 Windows 10 / 11 x64

  1. 从 Releases 下载 *-Windows-x64-Setup.exe，双击安装
  2. 从开始菜单或桌面快捷方式启动，等待进度结束
当前用户安装，无需管理员权限。便携版请完整解压 *-Portable.zip，运行 LocalModelSearch.exe。

🍎 macOS 14+（Apple Silicon）

  1. 下载并打开 *-macOS-arm64.dmg，将应用拖入 Applications
  2. 从 Applications 启动 LocalModelSearch.app
Mac 仅作为预发布测试资产；CI 验收不等于实机 GUI、Finder 与 Gatekeeper 验收。应用为 ad-hoc 签名，未经 Apple 公证。
⚠️ 不支持 Intel Mac、Windows ARM，不承诺 GPU 加速。Windows 包未作正式代码签名。
先核对 Release 同页的 SHA-256 清单；确认来源后按系统针对该应用的选项继续，不要关闭全局安全机制。
仅开发者使用源码启动脚本：python scripts/setup.py（需自行准备 Python 3.11）。

使用说明

建库 → 检索 → 复用，三步完成一次形状查找。

① 建立检索库

「新建检索库」→ 选择放有 3D 模型的文件夹 → 等待索引完成。

② 检索相似模型

把查询模型拖入左侧卡片（或点击选择本地文件）→ 点「查找相似模型」。

③ 查看与复用

点击结果 3D 预览；「打开所在文件夹」定位磁盘位置；「以此模型继续检索」继续发散。

常见问题

遇到问题？先看这里，多数问题一句话能解决。

提示找不到 Python？
普通用户请下载 Release 中的 Setup.exe、Portable.zip 或 DMG；不要下载源码 ZIP 作为安装包。
首次打开有安全提示？
当前 Windows 未作正式代码签名，Mac 使用 ad-hoc 签名且未经 Apple 公证。核对下载来源和校验值后，查看系统针对该应用的提示；Mac 可查看“系统设置 → 隐私与安全性”。不要关闭 SmartScreen、Gatekeeper 或防病毒；若提示损坏或恶意软件，请停止并反馈。
配置和日志在哪里？
Windows：%LOCALAPPDATA%\LocalModelSearch；Mac：~/Library/Application Support/LocalModelSearch。
点击界面的“配置与日志”打开目录。主进程日志为 startup.log，后台日志在 sessions/<会话>/launcher.log。反馈前隐藏个人路径和会话令牌。
如何退出？需要开放防火墙吗？
关闭独立窗口即退出。独立窗口不可用时回退浏览器，请点击控制窗口的“退出”；关闭网页标签本身不会停止后台。服务仅监听 127.0.0.1，无需开放公网或局域网端口。
旧版本检索库如何导入？
关闭旧程序，在新界面点击“导入旧检索库”，选择旧的 data 文件夹。仅复制索引，不删除源目录，不覆盖目标已有库，不复制会话或配置。原模型路径必须继续存在；需要时按提示刷新索引。
支持哪些模型格式？
STEP/STP、STL、OBJ、3MF、PLY、 GLB/GLTF、OFF；单个文件最大 256 MB。
如何更新 / 卸载？
退出应用并备份用户数据后，Windows 运行新版安装程序；便携版解压到新目录；Mac 替换 Applications 中的应用。
Windows 从“已安装的应用”卸载，便携版移除程序目录，Mac 移除 .app。升级与卸载默认保留独立用户数据目录和源模型。
